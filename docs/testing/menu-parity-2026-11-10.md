# 多端菜单同步（2026-11-10）

本轮将 Mac 已修复的菜单位置、中文操作、选中图标对比度同步到其他客户端，保留各平台交互习惯。

## 改动

- Web：选中会话的更多按钮在悬停、键盘聚焦及菜单打开时保持白色；消息更多图标提高对比度，并保留菜单打开时的显示。右键/长按与更多按钮继续共用复制、收藏、批注、删除操作。
- Android/Windows：会话使用单个横向更多图标；浅蓝选中背景上使用深蓝图标。菜单打开时消息更多保持可见，整个气泡区域接受右键/长按，系统 Material 组件使用简体中文。消息更多原本已贴近气泡，保持布局并增加回归验证。
- iOS/iPadOS：共用 Apple 的中文菜单、操作定义和紧贴气泡的定位；触摸菜单按钮扩大到 44×44 点并预留空间，列表更多使用系统主前景色。iOS 保留原生长按菜单，Mac 保留处理文本右键冲突的 AppKit 适配。

## 验证

- Web 构建（含 TypeScript）与修改 CSS 格式检查通过；Chrome 实际打开选中会话菜单、右键消息卡片，确认中文操作正常。
- Flutter analyze 无问题，53 项测试全部通过。其中新增 7 项覆盖宽/窄屏两侧短消息布局、选中图标对比度大于 4.5、菜单打开状态、Android 图片长按、Windows 图片右键及普通点击预览。
- Apple macOS 与 iOS Simulator 构建通过；Info.plist 检查通过。
- 新 iOS Simulator 构建已安装并启动于现有 iPhone 18 Pro 模拟器；本轮电脑控制工具无法绑定 Simulator，未进行 iOS/iPad 视觉及触控实测。

## 范围与限制

- 未重新生成 APK、IPA 或 Windows 发布包，现有真机安装包需后续重新打包更新。
- Windows/Android 本轮以 Flutter 平台模拟 widget 测试验证，未做 Windows 原生构建或 Android 真机 GUI 验收。
- Flutter 消息正文原本不支持拖选文字，本轮保留复制菜单与链接点击，不增加文本选择功能。
- Web 构建仍有原有主包超过 500 KB 的提示，不影响本轮构建。

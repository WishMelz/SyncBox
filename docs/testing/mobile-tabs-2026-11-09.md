# 移动端消息 / 设置导航（2026-11-09）

## 页面结构

- Android 和 iOS 主界面分为“消息”“设置”两个标签。
- 消息页标题为“消息列表”，右上角单独提供新增会话图标，保留搜索、收藏和会话列表。
- 移动端列表移除重复的品牌标题、账号简介、刷新、设备和设置工具按钮。
- 进入手机会话后隐藏底部标签，保留会话自己的标题栏和输入区；返回后恢复列表和标签。
- Android 宽屏保留会话列表与详情并排布局，底部标签仍可切换设置。
- 设置集中展示账号、服务地址、同步状态、刷新、当前设备名称和 ID、设备管理、文件清理、两步认证、删除数据和退出登录。
- 切换标签保留未提交的设置内容。设置请求处理中、恢复码尚未确认保存时锁定切换。
- 内嵌设置页面的退出、会话失效和重置不再尝试关闭根页面，而是切换到相应的登录状态。

## 平台表现

- iOS 使用 SwiftUI 原生 TabView。iOS 26 及以上由系统提供 Liquid Glass 标签栏，较早系统使用原生半透明标签栏；最低系统仍为 iOS 17。
- iOS 保留原生导航返回及 iPad 分栏，设置作为独立标签，不再依赖消息页打开设置弹窗。
- Android 使用 Material 3 NavigationBar，白底、蓝色选中态，列表搜索改为紧凑圆角样式。
- Windows 与 macOS 保留桌面导航，共享设置内容补充账号和连接信息。

# 原生端 TG 风格与搜索高亮同步

本轮将 Web 的消息呈现和搜索高亮同步至 iOS/iPadOS/macOS（SwiftUI）与 Android/Windows（Flutter）。保留各平台系统导航和文件选择器。

## 范围

- 当前设备右侧浅蓝气泡，其他设备左侧白色气泡；设备名、底部时间、日期分隔与较小的更多按钮。
- 消息及会话的右键/长按菜单；复制、收藏、批注、删除仍复用原 API 与确认流程。
- 图片/文件纸夹菜单、简洁输入区与窄屏附件草稿滚动；保留失败草稿及手动再次发送，不自动补发。
- 正文、批注、附件名、会话标题/预览、收藏的关键词高亮；中文、大小写、字面符号、emoji 原文范围。
- 长批注命中后自动展开；附件名命中时显示完整内容；隐藏重复的附件/图片占位正文。
- HTTP(S) 链接识别、末尾标点裁剪；高亮不改复制文本或链接目标。Android 使用 ACTION_VIEW，Windows 使用 ShellExecuteW，Apple 使用系统链接行为。
- 搜索栏默认收起；Mac ⌘F，Flutter Ctrl/Cmd+F；Esc 关闭并清除筛选。Flutter 消息搜索采用 350ms 延迟查询并保留焦点。

## 验证

- Swift 核心测试：24 项通过、1 项真实后端集成测试按配置跳过。新增原文范围、HTTP(S) 链接、ISO 日期/日期分段测试。
- Flutter：40 项测试通过，包括新匹配逻辑及 390/1280px 界面、长按/右键、复制原文、链接目标、长批注展开、附件完整高亮、会话菜单、搜索快捷键与 390×340px 五附件布局。
- Flutter 静态分析：无 error/warning；旧代码仍有大括号风格 info。
- iOS Simulator、macOS Debug 目标编译验证；Android Debug APK 构建验证。

测试使用内存数据和 Mock HTTP，没有改动个人服务数据。测试发现并修复了搜索提交后失焦导致 Esc 不能收起的问题。

## 验证边界

Windows 共用 Dart 代码与界面经静态检查及测试，新增 Windows 原生链接通道尚未在 Windows 主机编译或运行。未进行本轮 iPhone/iPad/Android 真机触控、外部浏览器启动或系统文件选择器实测；小视口组件测试不代替真实软键盘测试。

Android 调试 APK 仅用于编译验证，未安装到设备；未导出新的 IPA、Windows 分发包或正式发布包。现有安装包需要重新构建安装后才能使用本轮功能。

# Telegram 风格 Web 工作台验证

## 范围

按用户最新决定撤回未交付的微信风格方向，改为 Telegram 风格的布局与交互。保留 SyncBox 的私有部署、无头像、无未读数字和手动发送语义；本轮未修改后端、个人数据库或原生客户端。

## 变更

- 白色侧栏与顶部导航，蓝色选中态，浅蓝灰聊天背景、浮动圆角输入栏。
- 当前设备消息浅蓝靠右，其他设备白色靠左；时间置于消息底部，按日期分段。
- 电脑右键、手机长按或更多按钮打开消息菜单，可复制、收藏、批注和删除；删除保持确认。
- 局域网 HTTP 复制兼容。在 Radix 菜单的焦点范围内创建临时选择区，避免焦点被菜单抢回导致复制为空。
- HTTP(S) 链接直接打开；其他输入由 React 作为纯文本渲染。
- 电脑 Enter 发送、Shift+Enter 换行，手机 Enter 换行；保留 ⌘/Ctrl+Enter。中文输入法 composing 和 keyCode 229 不触发发送。
- 搜索默认折叠，按钮或 ⌘/Ctrl+F 打开，Esc 关闭。纸夹菜单提供图片/文件选择。
- 根据移动端 visualViewport 限制输入区和附件区高度；长草稿加多个附件时保留可见发送入口。
- 搜索高亮复用同一组件，覆盖消息正文（含链接）、批注、附件文件名、会话标题/预览及收藏。按字面、忽略大小写匹配；Unicode 大小写扩展保留原始文本索引，跨链接边界也可高亮。匹配的长批注自动展开。

## 已验证

- TypeScript 检查、Vite 生产构建通过。构建保留单个压缩 JS chunk 略高于 500 kB 的体积提示，不影响构建结果。
- 15 项 Web 单元测试通过，包括新增链接处理、日期分组、搜索范围映射与 Unicode/特殊符号/跨链接高亮。
- `manual-send.browser.mjs` 回归通过：390/1280px 的发送失败与成功状态，草稿保留、网络恢复不补发、切换会话、附件失败/人工再发/取消上传。
- `telegram-workspace.browser.mjs` 基础回归通过：1280/913/390px 布局无横向溢出，蓝白气泡与左右对齐，逐条时间和按日分组。
- PC 右键与通过 Chrome CDP 触屏事件触发的手机长按通过；HTTP 复制、删除取消、批注焦点通过。
- Enter/Shift+Enter、中文输入法 composing/229 保护和手机回车换行通过。
- 390×340px 的长草稿和 5 附件场景中发送按钮可见；PC/手机图片大图打开关闭通过。
- `SYNCBOX_TEST_MODE=highlighter` 的 1280/390px 搜索回归通过：中文正文、大小写链接、折叠范围之后的批注、附件名、会话标题和收藏中的批注/文件名均正确高亮；清空后取消高亮，复制完整原文、链接地址保持不变。

所有浏览器验证使用独立 Chrome context，并拦截全部 API 为测试数据，不读取或更改个人消息。小视口测试模拟键盘压缩后的窗口高度，不代表 iPhone/Android 真机软键盘测试。原生安装包未重新构建。

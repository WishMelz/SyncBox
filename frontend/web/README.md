# SyncBox Web

React 19 + Vite 8 + TypeScript + Tailwind CSS 4 + shadcn/ui。

在仓库根目录执行 `npm ci`、`npm run dev:web`，访问 http://localhost:5173。使用 `npm run dev` 可同时启动前后端。

## 组件结构

- `src/components/ui/`：shadcn/ui 基础组件，源码可直接维护。
- `src/components/layout/`：跨页面共享布局与导航。
- `src/pages/`：页面组合。
- `src/hooks/`：请求状态与交互逻辑。
- `src/services/`：API 请求、响应校验。
- `src/lib/`：通用工具。
- `src/styles/`：Tailwind 主题与全局样式。

采用移动端优先布局：手机使用顶部导航与单列内容，PC 使用侧边栏、多列卡片。组件提供键盘焦点和服务状态播报；错误或超时会显示未连接，可手动重试。

添加 shadcn/ui 组件：

```sh
cd frontend/web
npx shadcn@latest add dialog
```

开发时 `/api` 代理到 `http://127.0.0.1:3000`，可通过 `.env` 中的 `API_PROXY_TARGET` 修改。该变量仅由 Vite 开发服务器使用。

构建命令为 `npm run build -w @syncbox/web`，产物位于 `frontend/web/dist/`。生产静态服务器须将 `/api` 转发到后端；`vite preview` 仅用于检查静态产物，不是生产服务。

当前提供登录与会话消息工作空间，接口调用集中在 services 目录。

基础 Button、Card、Badge 源码来自 shadcn/ui 官方 new-york 注册表（https://ui.shadcn.com/r/styles/new-york/），配置保存在 `components.json`。

生产可运行 `docker compose -f infra/docker/compose.yaml up --build -d`（仓库根目录），访问 http://127.0.0.1:8080。部署使用单个后端镜像，由 NestJS 同时提供 Web 静态资源和 `/api` 接口；可通过 `SYNCBOX_PORT` 调整宿主机端口。

## 会话工作空间

Web 已提供首次设置和登录、会话创建/重命名/删除、消息发送、搜索、复制、收藏及设备列表。手机单栏、PC 双栏。每 5 秒自动读取同账号其他设备的新内容，所有请求通过同域 /api 代理。会话删除会连同消息永久删除，界面提供确认。登录凭证只保存在当前标签页 sessionStorage，设备标识保存在 localStorage；退出会撤销当前会话。

## 图片与附件发送

点击输入框旁的纸夹按钮，在菜单中选择“图片”或“文件”，支持图片、PDF、Office 文档、压缩包等文件，也可拖入输入区，或用 ⌘V / Ctrl+V 粘贴剪贴板图片。普通文字粘贴保持原行为。每条消息最多 5 个文件，总大小不超过 20 MiB；空文件不允许发送。

发送前显示文件名、大小和图片缩略图，可逐个移除、附加文字。电脑端 Enter 发送、Shift+Enter 换行，也支持 ⌘/Ctrl+Enter；手机端回车换行，点击发送按钮提交。中文输入法确认候选词不会发送。显示上传进度，失败时保留草稿与文件，由用户手动再次发送。附件草稿按会话保留，刷新页面后清空。

消息中支持 JPEG、PNG、WebP、GIF 的静态图片预览及大图查看，其他格式显示文件卡片。所有附件可下载原始文件（图片也不转码、不丢失动画或元数据），中文文件名保留。会话和消息搜索支持文件名，不解析文件正文，也不做 OCR。浏览器仅复制图片链接/HTML 时不会自动下载远程图片，请复制图片本身或保存后选择文件。

附件及图片预览均经同域 /api 代理，带登录凭证读取，没有公共文件链接。本阶段仅升级 Web；其他客户端随后接入通用附件 API。旧单图片接口及历史图片显示保持兼容。


## 设置面板

工作台顶部的设置按钮提供闲置文件清理、两步认证和删除所有数据。闲置清理默认关闭，可设置 1–3650 天；按图片或附件最近上传、预览、下载时间判断，每 10 分钟执行一次，消息文字和文件名会保留。两步认证使用验证器动态码，开启时展示本地二维码和一次性恢复码；删除所有数据需要当前密码及确认文字，完成后回到首次设置页面。


## 工作台偏好

会话列表支持置顶，置顶会话排在最近活动之前；新建会话默认使用 `新建会话YYMMDD`，创建前仍可修改。侧栏提供独立的收藏入口，可搜索、分页、取消收藏和管理收藏消息。设备面板可修改当前 Web 设备名称，名称会在后续消息中显示。界面保留必要操作，移除头像和重复说明。

## 会话右键菜单与虚拟消息列表

在侧栏右键点击会话，可置顶/取消置顶、改名、删除。操作针对点中的会话，保留当前打开的会话；删除前会显示目标名称和确认提示。

消息区使用 react-virtuoso 按可视范围渲染，自动测量文字、图片和附件的高度。向上滚动按游标连续读取更早消息，每批 30 条，加载前后保持内容位置；搜索结果也可连续加载。最近 20 个会话/搜索视图在当前页面运行期间记住阅读位置。底部自动跟随新消息，浏览历史时保持位置；主动发送或点击“回到底部”回到最新。加载失败保留已有内容，顶部可手动重试。会话列表和收藏列表保留分页。

消息按当前登录设备 ID 区分：本机发送的消息靠右并使用浅蓝气泡，其他设备的消息靠左，保留设备名称，不显示头像和未读数字。气泡随内容收缩，每条消息的时间放在底部，聊天区按日期分段。电脑右键、手机长按或消息旁的更多按钮可复制、收藏、添加批注和删除；删除仍需确认。复制支持局域网 HTTP 的兼容方式，HTTP(S) 链接可直接打开。

## 消息批注

消息菜单中的“添加批注”或“编辑批注”可修改备注，每条消息一份、最多 2000 字符。批注以浅色竖线区域显示在正文下方，长批注可以展开。独立编辑弹窗保留失败草稿，删除批注需要二次确认且不删除消息。会话列表、当前会话和收藏搜索均支持批注关键词；收藏页可直接编辑。与 iOS/macOS 和 Flutter 使用同一字段和接口。

## Telegram 风格工作台（2026-11-09）

Web 使用白色会话侧栏、蓝色选中态、浅蓝灰聊天背景与底部浮动输入栏，保留 SyncBox 品牌。电脑左右双栏，手机单栏切换；搜索默认折叠，点击顶部搜索按钮或电脑 ⌘/Ctrl+F 打开，Esc 收起。移动端根据可视窗口调整高度，避免软键盘覆盖输入区。附件限制放在纸夹菜单里，聊天区不常驻显示操作说明。此轮只调整 Web，其他客户端尚未同步此视觉样式。

搜索结果会高亮正文、批注和附件文件名中的关键词，侧栏与收藏列表也使用相同高亮。按字面匹配，不区分大小写，支持中文及特殊符号；清空搜索后取消高亮。批注匹配时自动展开，文件名匹配时允许换行，方便看到命中位置。高亮不修改消息原文，复制内容和链接地址保持完整。

设置面板顶部的“当前设备”可修改当前登录设备名称（1–80 字符）。保存后设备列表同步显示，新发送的消息使用新名称；历史消息保留发送时的名称。空白名称不能提交，网络失败保留输入并允许重试。

## 浏览器设备标识

设置中的“当前设备”显示可复制的设备 ID 和绑定状态，设备列表同步显示 ID。Web 为每个站点/账号保存随机安装 UUID，并提供平台、最多三项语言、时区和触控点数量作为环境指纹；不会采集画布、音频、字体列表或硬件序列号，也不使用第三方识别服务。

登录及恢复会话时将这些信息绑定到后端设备记录。改名、浏览器升级、语言或时区变化不会改变设备 ID；相同浏览器的退出重登复用设备。不同浏览器配置、隐私窗口、不同访问域名/端口或清除站点数据会形成不同安装标识。不能凭指纹找回清空后的设备，也不能跨浏览器识别同一台物理机器。采用 getRandomValues 兼容局域网 HTTP，设备身份仍由账号登录保障。
